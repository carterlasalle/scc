# scc-context

Ranking, expansion, token budgets, and context pack rendering.

Part of [System Context Compiler](https://github.com/carterlasalle/scc) — compiles
code, config, infra and runtime evidence into a provenance-checked system model,
then emits task-specific context packs for coding agents.

This crate is a library in the SCC workspace. The user-facing tool is the
`scc` binary (`scc-cli`), installed from the
[installer](https://github.com/carterlasalle/scc/blob/main/docs/INSTALL.md) or
`cargo install scc-cli`.
