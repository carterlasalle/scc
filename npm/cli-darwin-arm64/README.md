# cli-darwin-arm64

The `scc` binary for macOS arm64 (Apple silicon).

Installed automatically as an optional dependency of
[`@carterlasalle/scc`](https://www.npmjs.com/package/@carterlasalle/scc) — you do
not install this package directly.

Source, docs and every other install path: <https://github.com/carterlasalle/scc>
